LENTERA — Premium Cinematic Editorial Redesign
===============================================

Versi ini berfokus pada peningkatan tampilan tanpa mengganti alur sistem utama.

Yang dipoles:
- Homepage dengan hero cinematic dan display cover buku dinamis.
- Identitas visual LENTERA: deep forest, ivory, warm gold, editorial typography.
- Navbar sticky/glass + menu responsive mobile.
- Book cards dengan depth, hover, subtle 3D interaction, dan reveal animation.
- Katalog, kategori, detail buku, keranjang, checkout, pesanan, form, login/register.
- User dashboard dan admin dashboard dibuat lebih premium dan konsisten.
- Sidebar admin, tabel, form CRUD, dan tombol diselaraskan dengan brand LENTERA.
- Favicon LENTERA baru.
- js/ui.js ditambahkan untuk micro-interactions dan mobile navigation.
- Responsive viewport ditambahkan pada halaman yang sebelumnya belum memilikinya.

Yang sengaja TIDAK diubah:
- Struktur database.
- Nama database/config koneksi.
- Alur session/login/logout.
- CRUD buku/kategori/pesanan/user.
- Keranjang, checkout, pembayaran, pesan, dan query utama yang sudah ada.

Catatan:
Project tetap menggunakan koneksi database yang sudah ada pada config/koneksi.php.
